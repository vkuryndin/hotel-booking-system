# ADR-002. JWT и межсервисная авторизация

**Статус:** принято (реализовано в учебном проекте; описание на 31.10.2026).

## 1. Контекст

Нужны роли USER/ADMIN, самостоятельная JWT-валидация сервисами и защита операций Saga от пользовательского доступа; Gateway не может быть единственной точкой контроля.

**Основание:** ТЗ Skillfactory/МИФИ, требования к микросервисам, безопасности, алгоритму занятости и распределённой согласованности; реализация в исходниках Hotel Booking System.

## 2. Решение

Пользовательский JWT сроком PT1H, Spring Security Resource Server на Gateway и бизнес-сервисах, `@PreAuthorize` на административных операциях, отдельный service JWT для Booking→Hotel, блокировка внутренних POST на Gateway и внутренний секрет доверенных запросов.

## 3. Подверженные решению продукты

Hotel Booking System — соответствующие компоненты: Booking Service и Hotel Service, API Gateway.

## 4. Рассмотренные варианты

**Вариант 1. Только Gateway валидирует JWT.** Один контур защиты, уязвим при прямом доступе к сервису.

**Вариант 2. JWT на каждом сервисе + отдельный служебный токен.** Независимая проверка прав и разграничение клиентских/сервисных действий.

**Вариант 3. Сессионная авторизация в общей БД.** Вводит общие сессии и связность; не соответствует JWT-требованию.

## 5. Сравнение вариантов

| Критерий | Приоритет | Вариант 1 | Вариант 2 | Вариант 3 |
|---|---|---|---|---|
| JWT и роли | MUST | Частично | Да | Нет |
| Защита прямого вызова | MUST | Нет | Да | Частично |
| Изоляция служебных операций | MUST | Нет | Да | Требует отдельного механизма |
| Простота конфигурации | SHOULD | Выше | Средняя | Ниже |

Приоритеты: **MUST** — обязательный; **SHOULD** — желательный; **COULD** — дополнительный. Оценки качественные, без вымышленных количественных измерений.

## 6. Последствия

Плюсы: defense in depth; раздельные пользовательские и служебные полномочия. Минусы: управление keystore/секретами, настройка нескольких security chain и риска рассинхронизации конфигураций. Прямые порты бизнес-сервисов дополнительно изолируются на сетевом уровне при production-развёртывании.
