# Swagger / OpenAPI

Для Booking Service и Hotel Service используется springdoc-openapi (OpenAPI 3) с JWT Bearer Security Scheme `bearerAuth`. Спецификации генерируются из REST-контроллеров, DTO и `@ApiResponse` и отражают фактически опубликованные операции сервисов.

## Адреса

| Сервис | Swagger UI | Спецификация JSON |
|---|---|---|
| Booking Service | `http://localhost:8081/swagger-ui.html` | `http://localhost:8081/v3/api-docs` |
| Hotel Service | `http://localhost:8082/swagger-ui.html` | `http://localhost:8082/v3/api-docs` |

В Swagger UI сервер для клиентских вызовов указан как `http://localhost:8080` (API Gateway). Сначала запустите все сервисы и дождитесь их регистрации в Eureka.

## Аутентификация

Регистрация (`POST /api/users/register`) и вход (`POST /api/users/login`) выполняются без JWT. Для остальных клиентских операций получите токен через вход, нажмите **Authorize** и укажите JWT. Токен действует один час. Роль `ADMIN` требуется для операций записи в каталог, управления пользователями, статистики и восстановления Saga; `USER` видит только свои бронирования. Проверки полномочий выполняются в backend независимо от Swagger UI.

## Ответы и описание ошибок

У операций объявлены коды успешных и ошибочных HTTP-ответов. Коды 4xx/5xx, включённые в `@ApiResponses`, связываются с моделью `ErrorResponse` через `OpenApiConfig.errorResponseCustomizer`. Объект содержит `timestamp`, `status`, `code`, `message`, `path`, `traceId` и при необходимости `fieldErrors`. Глобальная настройка дополняет **существующие** описания ошибок и не создаёт отсутствующие записи автоматически.

| Код | Назначение |
|---|---|
| `400` | Некорректный запрос или параметры |
| `401` | JWT отсутствует, истёк или недействителен |
| `403` | Недостаточно полномочий, доступ к чужим данным или запрещённый внутренний путь |
| `404` | Запрошенная сущность отсутствует |
| `409` | Конфликт уникальности, состояния, даты или ключа идемпотентности |
| `413` / `415` | Превышение размера / неподдерживаемый тип загружаемого файла |
| `429` | Превышение лимита запросов |
| `503` | Зависимый сервис временно недоступен или Saga не может завершиться |

В Swagger UI раздел **Responses** описывает возможные ответы операции, а **Server response** показывает фактический ответ после `Execute`. Подробные параметры и ограничения — в [REST API](api.md).

## Служебные маршруты

`RoomReservationController` (подтверждение и освобождение слота) исключён из OpenAPI через `@Hidden`; операции предназначены для Booking Service, а не пользовательского клиента. `GET /api/users/token-status` реализован в Booking Service для Gateway и исключён из спецификации Booking Service через `@Hidden`. Внешний вызов через Gateway заблокирован: этот маршрут не предназначен для публичной проверки JWT.

## Проверка спецификаций

После запуска приложений откройте `/v3/api-docs` каждого сервиса и убедитесь, что раздел `paths` содержит операции контроллеров, в `components.securitySchemes` указан `bearerAuth`, а ссылки `#/components/schemas/ErrorResponse` разрешаются. Доступность Swagger UI сама по себе не означает, что вызов защищённого метода завершится успешно: валидацию токена и ролей выполняет Spring Security.
